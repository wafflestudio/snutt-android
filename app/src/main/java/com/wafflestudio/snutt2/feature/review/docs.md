# 강의평 기능 명세

## 기능 개요

강의평은 유저가 수강한 강의에 대한 강의평을 작성, 검색, 조회할 수 있는 기능이다.

- **강의평 조회**: 필터 버튼을 클릭하여 원하는 강의평의 필터를 설정할 수 있으며, `검색 화면으로 이동 -> 검색 -> 검색 결과 중 하나를 클릭해 강의평 상세로 이동`의 흐름으로 진행
- **강의평 작성**: 강의평 작성 화면에서 `수강 학기 선택 -> 총평 및 세부 평가 -> 강의 리뷰 작성 -> 작성 완료`의 흐름으로 진행
- **내 강의평 조회**: 강의평 메인 화면에서 `나의 강의평`을 클릭해 내가 작성한 강의평을 확인 가능

## ID 계약

강의평 상세 화면은 **강좌 하나에 달린 강의평 목록**을 보여준다. 개별 강의평 하나를 보여주는 화면이 아니다. [v2 API](https://snutt-api-dev.wafflestudio.com/v3/api-docs/v2)는 여러 학기의 강의를 묶는 `Course`, 특정 학기의 `Lecture`, 사용자가 작성한 `Evaluation`을 구분한다.

| 대상 | 앱의 필드 | 의미와 용도 |
| --- | --- | --- |
| 강좌 ID | `EvaluatedCourse.courseId: Long`, `LectureReviewInfo.courseId: String` | **같은 v2 `Course.id`**를 나타낸다. 강좌 상세와 강의평 목록 조회에 사용한다. `LectureReviewInfo`는 기존 응답의 `evLectureId`를 문자열로 보관하며, 빈 문자열은 ID가 없는 상태다. |
| 학기별 강의 ID | v2 `Lecture.id: Long` | 해당 학기에 개설된 강의의 ID. 강의평 작성 API의 `lectureId`에 사용한다. 강좌 상세 응답의 `lectures`에서 선택한 학기에 맞는 강의를 정해야 한다. |
| 개별 강의평 ID | `LectureReview.id: Long` | v2 `Evaluation.id`. 좋아요·신고·수정·삭제 등 개별 강의평 대상 작업에 사용한다. 강좌 상세의 ID와 다르다. |

`evLectureId`와 v2 `courseId`의 대응은 [기존 검색 응답의 서버 매핑](https://github.com/wafflestudio/snutt-v2/blob/develop/v1compat/src/main/kotlin/com/wafflestudio/snutt/v1compat/snutt/V1CompatLectureSearchController.kt#L84-L90) 및 [강좌의 호환 응답 매핑](https://github.com/wafflestudio/snutt-v2/blob/develop/v1compat/src/main/kotlin/com/wafflestudio/snutt/v1compat/snutt/dto/LegacyLectureDtos.kt#L96)에서 확인했다. 이 계약은 **현재 서버에서 받은 값**에 대한 것이며, `evLectureId`를 개별 강의평 ID로 해석해서는 안 된다.

앱의 `Lecture.id: String`은 v2의 학기별 `Lecture.id: Long`과 타입도 다르고, 데이터 출처에 따라 의미도 다르다. 검색 결과에서 만든 `SearchedLecture.id`는 검색 강의 ID지만, 시간표 DTO에서 만든 `SearchedLecture.id`와 `SyllabusLecture.id`는 시간표 항목 ID다. `SyllabusLecture.originalLectureId`는 원래 강의 ID를 별도로 보관한다. 따라서 강의평 작성 시 임의의 `Lecture.id`를 v2 작성 API의 `lectureId`로 바로 전달하지 말고, 선택한 `CourseBook`에 대응하는 강의 ID를 확인해야 한다.

## 유저 시나리오

### 시나리오 1: 강의평 조회

1. 유저가 강의평 메인 화면에서 필터 버튼을 클릭
    - 필터 선택 바텀시트가 뜸
      - 필터를 클릭해 필터를 설정 혹은 설정 해제할 수 있음
      - 필터 고정 버튼을 누르면 바텀시트가 닫히고, 필터가 반영됨
      - deemer 영역이나 X 버튼을 누르면 바텀시트가 닫히고, 필터가 반영됨. // TODO 필터가 반영되는 것인지 확인 필요

2. 유저가 앱을 껐다가 켠다.
    - 앱을 끄기 전에 선택했던 필터들이 선택된 상태로 유지됨
    - 강의평 메인 화면에서 선택된 필터를 클릭해 선택 해제(삭제)할 수 있음

3. 유저가 검색창을 클릭한다.
   - 검색 화면으로 이동
     - 화면 상단 '강의평' 제목이 사라짐
     - 화면 중앙에 텍스트 및 돋보기 표시: '강의명 및 교수명을 검색하세요'
     - 키보드가 열림(imeAction 검색)
     - 검색창의 hint text가 사라짐
     - 검색창에 X가 생기고, 이를 눌러 검색어를 전체 삭제할 수 있음

4. 유저가 원하는 강의를 검색한다.
   - 필터와 검색어에 맞는 강의평 목록이 보여짐
   - 강의평 수, 평균 평점, 강의명, 교수명을 확인할 수 있음
   - 결과가 없는 경우 검색 결과가 존재하지 않는다는 결과가 보여짐

5. 유저가 강의평을 클릭한다.
   - 강의평 세부 화면으로 이동함
     - 해당 강의의 세부 정보, 항목별 평균 평점을 확인할 수 있음
     - 해당 강의의 모든 강의평을 추천순, 최신순으로 확인할 수 있음
     - 강의평 작성 버튼을 눌러 해당 강의의 강의평을 작성할 수 있음

### 시나리오 2: 강의평 작성

1. 유저가 강의평 작성 버튼을 누름
   - 수강 학기를 선택함(기본은 현재 학기)
   - 총점, 성적, 강의력, 유익성, 과제량에 대한 평점을 각각 매길 수 있음
   - 강의 리뷰를 최소한 20글자 작성함
     - 20글자를 작성하지 않은 경우 강의평을 작성할 수 없음
   - 작성완료 버튼을 눌러 강의평 작성을 완료함

### 시나리오 3: 내 강의평 조회

1. 유저가 나의 강의평 버튼을 누름
    - 나의 강의평 화면으로 이동
      - 학기별로, 자신이 작성한 모든 강의의 강의평을 확인할 수 있음

## 네비게이션 구조

### 진입점

1. **홈 > 강의평 홈**
   - 어떤 화면에서도 바텀 바가 있다면, 바텀 바를 눌러 강의평 홈으로 이동할 수 있음
   - 현재는 `NavigationDestination.Home(initialTab = "review")`로 홈의 강의평 탭에 진입
   - 강의평 홈으로 직접 연결되는 DeepLink는 현재 없음

2. **검색 결과·강의 상세·북마크 등 > 강의평 상세**
   - 현재는 `NavigationDestination.Review(reviewId, lectureId, referrer)`로 바텀시트에 진입

### 화면 간 이동

```

  ├─ 필터 버튼 클릭 → 필터 선택 바텀시트 Open

  ├─ 강의평 셀 클릭 → 강의평 상세
  ├─ 나의 강의평 클릭 → 나의 강의평
  ├─ 전체 강의평 클릭 → 강의평 전체보기
  ├─ 강의평 작성 클릭 → 강의평 작성
  └─ ForceLogout (인증 에러) → Onboard (navigateAsOrigin)

  └─ 필터 고정 버튼 클릭 → 바텀시트 Close

  └─ 강의평 검색 결과 셀 클릭 → 강의평 상세

  └─ 강의평 작성 클릭 → 강의평 작성

나의 강의평
  ├─ 뒤로가기 클릭 → 이전 화면

  └─ 작성완료 클릭 → 이전 화면 // 모든 화면에 대해 이전 화면으로 떨굴지는 확정 X, 만약 아닌 경우가 있다면 해당 강의 상세로 이동
```
